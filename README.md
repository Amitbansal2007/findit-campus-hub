# FindIt Campus Hub

Act as a professional UI/UX designer and frontend developer.

Create a modern, premium and responsive website named "FindIt – Campus Lost & Found".

The purpose of this website is to help college students report lost belongings, report found items and find their belongings through a centralized platform.

For this first version, focus on creating a beautiful and professional frontend.

Design requirements:

Modern, clean and premium interface.

White and dark navy blue color scheme with subtle gradients.

Professional typography and spacing.

Fully responsive design for mobile and desktop.

Smooth navigation and subtle animations.

Create these sections:

Home page with a hero section introducing FindIt.

Search bar to search for lost and found items.

Recent Lost Items section.

Recent Found Items section.

Report Lost Item button.

Report Found Item button.

How It Works section with three simple steps.

AI Smart Matching introduction.

AI Assistant chatbot interface.

Footer with project information.

Create separate pages or functional navigation for:

Home

Browse Items

Report Lost

Report Found

Login / Register

Use realistic sample items such as college ID cards, wallets, books, keys, water bottles and earphones.

Make the design visually impressive but keep the interface simple and easy to use.

Important: Do not build a static-looking landing page only. Use reusable React components and functional navigation. We will integrate Supabase database, authentication and Gemini AI in subsequent development steps.

Generate the initial website with clean and organized React code.
